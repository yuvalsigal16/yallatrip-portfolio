# שלב 11: שיתוף

| יכולת | איך |
| --- | --- |
| מי רואה | בהגדרות הטיול: **פרטי** (ברירת המחדל) / **עם קישור** / **ציבורי** |
| קישור | נוצר קישור אקראי באורך 64 תווים, עם כפתורי "העתקה" ו"שליחה…" (תפריט השיתוף של הטלפון). חזרה ל"פרטי" מבטלת את הקישור, וקישור חדש יהיה שונה |
| דף משותף | `/s/<קישור>`, בלי צורך להתחבר: ימים, תחנות, שעות והערות לתחנות, קישור לכל מקום ב-Google Maps, ו"כל היום ב-Google Maps" כמסלול הליכה |
| שכפול | "שכפול לטיולים שלי" (אחרי התחברות): עותק מלא ופרטי, עם הימים, שמות הימים, התחנות, השעות והמלון. עריכת העותק לא משנה את המקור |
| פרטיות | הערות אישיות על מקומות לא מוצגות בקישור ולא מועתקות. זהות הבעלים לא נחשפת. דף של קישור פרטי מסומן ל-Google כ"לא לאינדקס" |

**החלטה טכנית:** פונקציית ההעתקה (`copy_trip_internal`) משמשת גם את החנות בשלב 12. אי אפשר לקרוא לה ישירות מהדפדפן, כי אחרת מישהו היה יכול להעתיק טיול פרטי של משתמש אחר. יש לה בדיקה משלה.

**בדיקות:** ‏11 בבסיס הנתונים (`06_sharing_tests.sql`) ו-3 בלוגיקה.

**בדיקה ידנית:**
1. בהגדרות בוחרים "עם קישור" ומעתיקים.
2. פותחים את הקישור בחלון גלישה בסתר: רואים את הטיול בלי להתחבר.
3. "שכפול לטיולים שלי": מבקש להתחבר (עם משתמש אחר), ואחר כך נפתח עותק בשם "... (עותק)".
4. מחזירים את הטיול המקורי ל"פרטי": הקישור הישן מציג "לא נמצא".
